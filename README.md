# FocusHub
A productivity web app to manage notes, tasks, and goals in one unified workspace.
# Problem 
Users often store notes, tasks, and goals in different places, making it difficult to stay organized and track progress efficiently.
# Target Users
Anyone who wants to manage notes, tasks, and goals from a single platform.
# Solution
FocusHub brings everything into one place and organizes it into
-Notes 
-Tasks
-Goals 
This makes information easier to access and manage.
# Core Features
1.	Notes Management - Add, Edit, Delete notes
2.	Tasks Management - Add, Edit, Delete tasks
3.	Goals Management- Add, Edit, Delete, Add progress in Goals
4.	Dashboard overview
